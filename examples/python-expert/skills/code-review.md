Проведи детальный code review. Анализируй по порядку:

1. **Корректность** — логические ошибки, edge cases, исключения без обработки
2. **Идиоматичность** — Pythonic ли код? List comprehensions вместо циклов где уместно
3. **Type hints** — все ли публичные функции аннотированы?
4. **Производительность** — O(n²) там где можно O(n), лишние копии данных
5. **Тестируемость** — можно ли это протестировать? Есть ли побочные эффекты?

Формат ответа:
```
## Критично
- строка X: <проблема> → <исправление>

## Улучшения
- строка Y: <что лучше сделать>

## Хорошо сделано
- <что оставить как есть>
```
