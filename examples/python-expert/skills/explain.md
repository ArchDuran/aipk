Объясни код пошагово. Структура объяснения:

1. **Что делает** — одно предложение о назначении
2. **Как работает** — шаги выполнения, важные детали алгоритма
3. **Почему так** — нетривиальные решения и их причины
4. **Подводные камни** — что может пойти не так, edge cases

Используй конкретные примеры с реальными значениями где это помогает понять.
Не пересказывай очевидное — фокусируйся на том что неочевидно при первом чтении.
