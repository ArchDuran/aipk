# Ограничения формата

## Жёсткие (принципиальные)

### Embedding space lock

Эмбеддинги в KNOW секции созданы конкретной моделью.  
При смене embedding модели — семантический поиск сломается.

**Смягчение:**
- `embedding_model` хранится в META
- Рантайм при несовпадении предлагает пересчитать
- Можно хранить raw chunks отдельно — тогда пересчёт автоматический

### Статичные знания

База знаний заморожена в момент сборки.

**Смягчение:**
- `aipk update` — пересобрать KNOW секцию из обновлённых источников
- `LIVE` секция (v2) — URL источников для автообновления

### Скиллы — только промпты

Навыки "подталкивают" поведение, но не гарантируют его.

**Смягчение:**
- Сочетать с grammar-based structured output (llama.cpp поддерживает)
- Добавить тесты качества в `EVAL` секцию (v2)

### Контекстное окно

RAG инжектирует N чанков, у модели есть лимит.

**Смягчение:**
- `rag_top_k` в META — настраивается под размер модели
- Компрессия чанков перед инжекцией
- Map-reduce для больших запросов

### Инструменты — не исполняемые файлы

В `.aipk` нельзя безопасно упаковать бинарники.  
TOOL секция содержит только конфиги MCP-серверов.  
Сами серверы должны быть установлены на машине.

**Смягчение:**
- Добавить `dependencies` в META с инструкцией по установке
- Рантайм проверяет наличие инструментов при загрузке

## Мягкие (решаемые в v2)

| Ограничение | Решение |
|-------------|---------|
| Нет diff/patch — нельзя обновить часть пакета | Секционный патч-формат |
| Нет цифровой подписи | `SIGN` секция + публичный ключ автора |
| Инкрементальное добавление знаний требует перепаковки | Append-only режим для KNOW |
| Нет версионирования чанков | SemVer для пакетов + changelog |
